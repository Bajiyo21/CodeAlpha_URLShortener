# 🔗 LinkVault – Premium URL Shortener

A modern URL shortening web application built using **Django REST Framework** and **SQLite** with a premium **Glassmorphism UI**.

## ✨ Features

* 🔗 Shorten long URLs instantly.
* 🚀 Automatic redirect using unique short codes.
* 📊 Click counter analytics.
* 📱 Premium responsive Glassmorphism interface.
* 📋 One-click copy shortened URL.
* 📈 URL History Dashboard with analytics.
* 🎯 Built with Django REST Framework.

## 🛠️ Tech Stack

* Python
* Django
* Django REST Framework
* SQLite
* HTML5
* CSS3 (Glassmorphism UI)
* JavaScript

## 🚀 Run Locally

```bash
git clone <repository-url>
cd CodeAlpha_URLShortener

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate
python manage.py runserver
```

Open **http://127.0.0.1:8000/** in your browser.
